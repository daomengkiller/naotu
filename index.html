云端设置（GitHub 私有仓库）

在 GitHub → Settings → Developer settings → Personal access tokens 生成，勾选 repo 权限（Fine-grained 需勾选 Contents 读写）。Token 仅保存在本浏览器 localStorage 中。
可以是一个专门存放数据的 私有仓库（新建时不要勾选 README，或已有空仓库均可）。脑图文件会保存在该仓库 mindmaps/ 目录下。
脑图 .km 文件在仓库中的存放目录，默认 mindmaps。

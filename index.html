云端设置（GitHub 私有仓库）

在 GitHub → Settings → Developer settings → Personal access tokens 生成，勾选 repo 权限（Fine-grained 需勾选 Contents 读写）。Token 会用你的访问密码加密后保存在本浏览器，只需填写一次，以后解锁即自动使用。
可以是一个专门存放数据的 私有仓库（新建时不要勾选 README，或已有空仓库均可）。脑图文件会保存在该仓库 mindmaps/ 目录下。
脑图 .km 文件在仓库中的存放目录，默认 mindmaps。

打开脑图（本地 + 云端）

点击文件打开，鼠标悬停可删除。「云端」= 已同步到 GitHub，「本地」= 仅存本浏览器。

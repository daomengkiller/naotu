# 我的脑图（KityMinder 自部署）

百度脑图官方开源内核（[kityminder-editor](https://github.com/fex-team/kityminder-editor)）的自部署版本，界面和操作与百度脑图一致，**原生支持打开百度脑图的 `.km` 数据文件**。数据保存在你自己的云端私有仓库（GitHub 或 Gitee）中，多设备自动同步；未配置云端时自动保存到浏览器本地。

## 在线地址

**https://daomengkiller.github.io/naotu/**

## 功能特性

- 🔒 **页面密码保护**：首次使用设置访问密码，之后每次打开页面都需输入密码（密码不存明文，PBKDF2 派生）
- 🔐 **数据加密（内容级保护）**：脑图内容用你的密码 AES-256 加密后再上传云端，云端和传输中均为密文；即使网站公开、仓库泄露，没有密码也读不了内容（2025 新增）
- 🗝️ **Token 简化**：云端 Token 用密码加密后保存在浏览器，**只需填写一次**，之后解锁自动使用
- 💾 **本地优先存储**：没有 Token / 断网时，脑图自动保存到浏览器本地（localStorage），配置云端后本地+云端双写
- 📂 **文件列表**：「打开脑图」列出全部脑图（本地 + 云端），带来源标记，点击选择打开，悬停可删除
- ☁️ **多后端云端**：支持 **GitHub** 和 **Gitee（码云）** 两种云端存储，设置里一键切换；Gitee 国内访问更快
- 🔄 **多设备同步**：配置云端仓库后，任意设备保存自动同步，天然带版本历史

## 第一次使用（5 分钟配置）

1. 打开 **https://daomengkiller.github.io/naotu/**
2. 首次访问会提示**设置访问密码**（至少 4 位），设置后自动进入编辑器
3. 点击右上角 **「设置」**，选择**存储后端**（GitHub / Gitee / 仅本地），填入：
   - **Token**：对应平台的个人访问令牌（见下方"生成 Token"）
   - **仓库名**：如 `daomengkiller/naotu-data` 或 Gitee 的 `用户名/仓库名`
   - **云端目录**：`mindmaps`（默认）
   - **自动保存**：开启
4. 点「保存设置」，点击 **「新建」** 输入名称创建第一张脑图，点 **「保存」** 上传到云端。

> 不填 Token/仓库也可以正常使用：脑图会保存在**本浏览器**中（本地模式）。

> Token 会用你的访问密码加密后保存在**当前浏览器** localStorage 中，不会明文存储，也不会上传到任何地方（网站本身是纯静态的）。

### 生成 GitHub Token

1. 打开 https://github.com/settings/tokens/new
2. 勾选 **repo**（完整仓库权限）；或选择 **Fine-grained token**，仓库访问选你的数据仓库，权限勾选 **Contents: Read and write**
3. 点 **Generate token**，复制 `ghp_...` 或 `github_pat_...` 开头的字符串
4. 粘贴到网站「设置」里的 Token 输入框（**只需填这一次**）

### 生成 Gitee（码云）Token（国内推荐）

1. 注册/登录 https://gitee.com
2. 右上角头像 → **设置** → **安全设置** → **私人令牌** → 生成新令牌（勾选 **projects** 权限）
3. 创建一个**私有仓库**用于存脑图（如 `naotu-data`）
4. 把私人令牌和仓库名（`用户名/仓库名`）填入网站「设置」，后端选 **Gitee**，保存即可

> Gitee 服务器在国内，访问速度远快于 GitHub，国内用户推荐使用。

### Gitee 一键登录（推荐，免输 Token）

设置里选 Gitee 后端后，会出现「Gitee 一键登录」区域，只需配置一次：

1. 打开 https://gitee.com/profile/applications → **创建应用**（第三方应用）
2. 填写应用信息：
   - **回调地址**填本页面网址：`https://daomengkiller.github.io/naotu/`
   - **权限**勾选 `projects` 和 `user_info`
3. 创建后复制 **Client ID** 和 **Client Secret**，填入网站设置里（加密保存，仅存本浏览器）
4. 点「保存应用信息」→ 点「**使用 Gitee 登录**」→ 在 Gitee 页面点授权
5. 自动跳回后即登录成功，**以后无需再输入任何 Token**（过期自动刷新）

> 说明：OAuth 登录的 access_token 有效期 1 天，本工具会用 refresh_token 自动续期；
> 若长期未使用导致登录失效，重新点一次「使用 Gitee 登录」即可（通常 10 秒内完成）。
> Client Secret 加密保存在本浏览器，且只用于换取访问令牌，不会上传到任何服务器。

### 换设备 / 换浏览器

1. 新设备打开网址 → 首次会要求设置密码（新设备的访问密码，可与其他设备不同）
2. 在「设置」里填入同样的 Token 和仓库名（选择同样的后端）
3. 「打开脑图」即可看到云端全部文件；本地标记的文件是本设备独有的

### 导入百度脑图旧数据

1. 在百度脑图导出（或你已保存的）`.km` / `.xmind` / `.mm` 文件
2. 打开本网站，点编辑器左上角「文件」→「导入」→ 选择文件
3. 确认内容无误后点「保存」，数据即上传到你的私有仓库

## 数据安全说明

- **内容级加密**：脑图内容用你的访问密码派生密钥（AES-256-GCM）加密后上传云端，云端存储的是密文（`KMENC1:` 开头），任何人没有密码都读不了内容
- 数据存放在你的云端**私有仓库**中（GitHub 或 Gitee，二选一），只有你的账号可读写
- 每次保存产生一次 commit，天然带**历史版本**（可在平台网页查看/回溯每次保存）
- 建议定期在平台网页下载 `mindmaps/` 目录备份，或导出 `.km` 文件

### 数据加密注意事项

- **多设备**：数据密钥由"访问密码 + 固定盐"派生，**所有设备请设置相同的访问密码**，否则无法互相解密
- **修改密码**：修改访问密码后，数据密钥会改变——**云端已加密的脑图需用旧密码重新打开并保存一次**，才能用新密码解密（本地副本不受影响）
- **忘记密码**：无法找回，已加密的云端数据将永远无法解密（这是加密的意义所在），请务必牢记密码

## 常见问题

**Q: 忘记访问密码怎么办？**
本页面密码只存在浏览器本地，忘记后无法找回。解决：清掉该站点的浏览器数据（localStorage）后重新打开页面，重新设置密码、重新填 Token。**云端数据不受影响**（在云端私有仓库中），重新配置后「打开脑图」即可恢复。

**Q: 提示"认证失败"？**
Token 无效或权限不足。在「设置」里重新粘贴有效 Token（GitHub 勾选 repo 权限；Gitee 勾选 projects 权限）。

**Q: 国内访问慢/打不开？**
- 网站托管在 GitHub Pages，国内访问可能不稳定，可换网络或代理
- **云端存储建议改用 Gitee 后端**：Gitee 服务器在国内，读写速度远快于 GitHub API
- 没有网络也能用：未配置 Token 时自动本地保存，可随时用「保存」+「导入」手动备份

**Q: 自动保存失败？**
打开「设置」确认 Token、仓库名、后端选择正确，网络能访问对应平台 API。云端失败时数据已保存在本地，不会丢失。
